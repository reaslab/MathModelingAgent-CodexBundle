Bundled Fandol fonts for the Chinese LaTeX template.

Source: the Fandol font family distributed with TeX Live.
Developed by the Fandol team (Clerk Ma and Jie Su).

License: GNU GPL v3 with the GPL font exception. The complete license text is
in `COPYING`. Keep that file with the font files when redistributing them.

These files are included so `template_zh` can load CJK fonts by relative path
with a local XeLaTeX installation, without relying on system font names such
as SimSun or SimHei.
